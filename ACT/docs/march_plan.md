# 三月任务分配与进度规划 (3D 可视化接入) - v2

本月核心目标：完成设备 3D 模型构建、实时数据/告警与 3D 场景的深度联动，并完成闭环演示脚本。

## 👥 人员分配

### **前端组 (2 人)**
- **FE-1 (3D 交互专家)**:
  - 负责 Three.js 场景的高级配置、GLTF 模型加载、光源优化。
  - 实现 3D 对象的点击交互、相机动画（自动追踪告警设备）。
  - 实现告警时的视觉特效（如模型发光、悬浮警告图标）。
- **FE-2 (数据集成工程师)**:
  - 负责 3D 对象与 `deviceId` 的数据映射逻辑。
  - 集成 WebSocket 实时通知到 3D 场景中，实现秒级视觉反馈。
  - 开发 3D 场景中的设备详情弹出卡片 (Overlay)。

### **后端组 (4 人)**
- **BE-1 (核心逻辑与自动化专家)**:
  - 负责优化告警引擎，支持更复杂的设备健康度评分逻辑。
  - 编写 `simulate_scenario.py` 演示脚本，模拟真实的故障注入场景。
  - 负责后端业务逻辑的整体稳定性。
- **BE-2 (接口与标准工程师)**:
  - 负责 NGSI-LD 扩展，增加对 3D 空间坐标属性的支持。
  - 优化 WebSocket 推送的消息体，包含 3D 联动所需的特定标志。
  - 统一前端新页面所需的各种统计 API。
- **BE-3 (测试与质量保证工程师)**:
  - 负责编写后端单元测试和回归测试脚本。
  - 负责 API 接口压力测试，确保系统在高并发数据上报时的稳定性。
  - 协助 BE-1 完成演示脚本的场景验证。
- **BE-4 (MySQL 专项工程师)**:
  - 负责优化 MySQL 中 `DeviceStatusLog` 的时序查询性能（索引优化、分区策略）。
  - 实现告警数据的冷热分离存储（历史告警归档）。
  - 负责数据库备份策略和生产环境数据一致性维护。

---

## 📅 进度规划

### **第一阶段：Week 1 - 2（模型构建与静态绑定）**
- **前端**: 载入模型并实现基于设备状态的基础颜色映射。
- **后端**: 扩展 3D 坐标字段，完成 MySQL 索引初步优化。

### **第二阶段：Week 3 - 4（动态联动与 Demo 交付）**
- **前端**: 实现 WebSocket 实时视觉反馈与详情弹窗。
- **后端**: 完成 `simulate_scenario.py` 脚本，演示“故障-告警-确认-恢复”全业务流。

### **验收标准**:
1. 3D 场景能正常加载真实设备模型且与数据对应。
2. 告警产生后 2 秒内 3D 模型产生视觉反馈。
3. 演示脚本能流畅展示完整的系统闭环。
