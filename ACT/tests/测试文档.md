# ATC监控系统 - 测试文档

## 📋 测试团队核心职责

### 1. 测试与质量保证
- **编写单元测试和集成测试**：确保代码质量和功能正确性
- **进行API压力测试和性能测试**：验证系统在高负载下的稳定性
- **验证算法准确性和系统稳定性**：确保预测算法和监控逻辑的可靠性
- **协助其他成员进行功能测试和问题排查**：支持开发团队的功能验证
- **查找相关文件规定各个设备给定的阈值**：确保告警规则符合行业标准
- **完善告警规则**：基于设备阈值和行业标准优化告警配置

## 🧪 测试类型

### 1. 单元测试 (Unit Tests)
**文件位置**: `monitor/tests.py`

**覆盖范围**:
- 设备模型 (Device Model)
- 告警规则模型 (AlarmRule Model)
- 设备状态日志模型 (DeviceStatusLog Model)
- 告警模型 (Alarm Model)
- 告警事件模型 (AlarmEvent Model)
- 告警通知模型 (AlarmNotification Model)
- 序列化器 (Serializers)
- 业务逻辑 (Business Logic)

### 2. 集成测试 (Integration Tests)
**文件位置**: `tests/integration_tests.py`

**覆盖范围**:
- 认证流程 (Authentication)
- 设备管理 (Device Management)
- 告警规则管理 (Alarm Rule Management)
- 设备状态日志 (Device Status Logs)
- 告警操作 (Alarm Operations)
- NGSI-LD端点 (NGSI-LD Endpoints)
- 端到端工作流 (End-to-End Workflow)
- 错误处理 (Error Handling)

### 3. 压力测试 (Stress Tests)
**文件位置**: `tests/stress_test.py`

**测试场景**:
- 基础API压力测试
  - 获取设备列表
  - 创建状态日志
  - 并发请求测试
- 算法性能测试
  - 趋势分析算法性能
  - 预测模型响应时间

## 📊 测试指标

### 压力测试等级评估
- 平均响应时间 < 100ms: ⭐⭐⭐⭐⭐ 优秀
- 平均响应时间 < 300ms: ⭐⭐⭐⭐ 良好
- 平均响应时间 < 500ms: ⭐⭐⭐ 一般
- 平均响应时间 < 1000ms: ⭐⭐ 较慢
- 平均响应时间 >= 1000ms: ⭐ 需要优化

## 🚀 快速开始

### 运行测试套件工具

推荐使用 `tests/run_tests.py` 工具运行各类测试：

- **运行所有测试**:
  ```bash

  ```

- **运行特定测试**:
  - 单元测试: `python tests/run_tests.py --unit`
  - 集成测试: `python tests/run_tests.py --integration`
  - 压力测试: `python tests/run_tests.py --stress`

## 🚨 告警规则配置指南

### 1. 规则层级
- **全局级**：适用于所有设备的通用规则（如电源电压、温度）
- **设备类型级**：适用于特定设备类型的规则（如VHF的信号强度、ILS的引导偏差）
- **设备级**：针对特定设备的个性化规则

### 2. 严重程度
- **INFO**：信息性告警，无需立即处理
- **WARN**：警告性告警，需要关注
- **ERROR**：错误告警，需要及时处理
- **CRITICAL**：严重告警，需要立即处理

### 3. 告警规则配置示例

#### VHF设备信号强度告警
```json
{
  "name": "VHF信号强度告警",
  "level": "DEVICE_TYPE",
  "device_type": "VHF",
  "metric": "signal_strength",
  "operator": "<",
  "threshold": -70,
  "severity": "WARN",
  "cooldown_seconds": 300,
  "auto_clear": true
}
```

#### ILS引导偏差告警
```json
{
  "name": "ILS LOC引导偏差告警",
  "level": "DEVICE_TYPE",
  "device_type": "ILS",
  "metric": "loc_guidance_deviation",
  "operator": "abs>",
  "threshold": 1.5,
  "severity": "ERROR",
  "cooldown_seconds": 120,
  "auto_clear": true
}
```
