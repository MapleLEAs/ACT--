ATC监控系统 - 项目启动与数据生成说明

## 项目结构

```
项目后端框架/
├── frontend/           # 前端代码
├── monitor/            # 后端Django应用
├── atc_monitor/        # Django项目配置
├── tests/              # 测试脚本和文档
│   └── test_environment.py  # 测试环境设置脚本
├── manage.py           # Django管理脚本
└── requirements.txt    # Python依赖
```

## 一、启动后端服务

### 1. 安装依赖

```bash
cd 项目后端框架
pip install -r requirements.txt
```

### 2. 数据库初始化

```bash
python manage.py migrate
```

### 3. 创建超级用户（可选）

```bash
python manage.py createsuperuser
```

### 4. 启动后端服务

```bash
python manage.py runserver
```

后端服务将运行在：`http://127.0.0.1:8000`

## 二、启动前端服务

### 1. 安装依赖

```bash
cd 项目后端框架/frontend
npm install
```

### 2. 启动前端开发服务器

```bash
npm run dev
```

前端页面将运行在：`http://localhost:5173`

## 三、生成测试数据

### 1. 使用测试脚本生成数据

在后端服务运行的情况下，执行测试脚本：

```bash
cd 项目后端框架
python tests/test_environment.py
```

### 2. 脚本功能说明

测试脚本 `test_environment.py` 会自动执行以下操作：

#### 2.1 清理现有数据

清理所有相关表的数据：
- 告警通知（AlarmNotification）
- 告警事件（AlarmEvent）
- 告警记录（Alarm）
- 设备状态日志（DeviceStatusLog）
- 告警规则（AlarmRule）
- 设备（Device）

#### 2.2 创建测试账号

创建两个测试账号：
- **管理员账号**: admin / admin123456
- **测试账号**: testuser / test123456

#### 2.3 创建告警规则

创建3条告警规则：
1. **VHF信号强度过低告警** - 信号强度 < -85.0 时触发
2. **ILS引导偏差超限告警** - 引导偏差 > 1.5 时触发
3. **设备离线告警** - 设备离线时触发

#### 2.4 上传示例数据

创建2台设备：
- **VHF-001**: 甚高频通信设备
- **ILS-001**: 仪表着陆系统

上传数据包括：
- VHF设备的正常数据（信号强度 -60）
- VHF设备的告警数据（信号强度 -90，触发告警）
- ILS设备的正常数据（引导偏差 0.5）
- ILS设备的告警数据（引导偏差 2.5，触发告警）

#### 2.5 数据生成统计

每次运行脚本大约会生成以下数据：
- **用户**: 2个（管理员账号和测试账号）
- **告警规则**: 3条（VHF信号强度、ILS引导偏差、设备离线）
- **设备**: 2台（VHF-001、ILS-001）
- **状态日志**: 4条（2条正常数据 + 2条告警数据）
- **告警记录**: 2条（VHF和ILS各1条，由告警数据自动触发）

**总计**: 约13条数据

## 四、访问地址

| 服务 | 地址 | 用途 |
|------|------|------|
| 前端页面 | http://localhost:5173 | 用户操作界面 |
| 后端API | http://127.0.0.1:8000/api/ | API接口 |
| Django管理后台 | http://127.0.0.1:8000/admin/ | 后台管理 |
| 设备列表 | http://localhost:5173/devices | 查看设备信息 |
| 告警中心 | http://localhost:5173/alarms | 查看告警信息 |

## 五、测试流程

1. 使用 `admin/admin123456` 登录前端
2. 访问设备列表，查看两台测试设备
3. 访问告警中心，查看自动生成的告警
4. 使用 `testuser/test123456` 测试数据权限（如需测试多用户场景）

## 六、后端框架打包

### 6.1 创建Python包

项目已配置 `setup.py` 文件，可以作为Python包安装：

```bash
cd 项目后端框架
pip install -e .
```

### 6.2 创建发布包

使用打包脚本创建压缩包：

```bash
cd 项目后端框架
python package_backend.py
```

打包文件将生成在项目根目录的上级目录，文件名格式：`atc-monitor-backend_日期时间.zip`

## 七、注意事项

1. 确保后端服务和前端服务都在运行
2. 测试脚本会清理现有数据，请谨慎使用
3. 测试数据用于开发和测试环境，请勿在生产环境使用
4. 如果遇到数据库连接问题，请检查数据库配置
5. 打包文件包含完整的后端框架代码，可用于部署和分发
